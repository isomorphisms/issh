# RFC mirror notice

The files under `text/` are intended to be **unmodified full copies** of the
plain-text editions published by the RFC Editor at:

    https://www.rfc-editor.org/rfc/rfcNNNN.txt

They are reference material for implementing SSH. They are not relicensed
under libssh2's `COPYING` file. Each RFC retains the copyright, authorship,
legal notices, status, and warranty language printed in that RFC.

For IETF-stream documents, the IETF Trust states that unmodified IETF
Documents may be copied, published, displayed, and distributed in full. The
licensing rules applicable to a particular RFC are the rules in effect when
that RFC was published; older RFCs can therefore be governed by earlier IETF
copyright policies rather than the current Trust Legal Provisions.

Canonical legal information:

- IETF Trust Legal Provisions: https://trustee.ietf.org/license-info
- IETF Trust TLP FAQ: https://trustee.ietf.org/documents/trust-legal-provisions/copyright-policy-and-tlp-faq/
- RFC Editor: https://www.rfc-editor.org/

Do not treat the prose of an RFC as BSD-licensed source code. RFC Code
Components have separate licensing rules. For modern IETF documents, consult
the RFC's own notice and the IETF Trust Legal Provisions before extracting or
modifying a Code Component.

The authoritative document is the RFC Editor copy. This directory is only a
convenience mirror.
